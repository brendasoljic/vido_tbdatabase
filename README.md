# vido_tbdatabase
Shiny dashboard for exploring Mycobacterium tuberculosis gene expression and proteomics data.

The data folder holds all of the datasets being used by the app - just upload any new datasets there and then use the same format as shown in the code to input a new file. Note - header row needs to be number 1.

Currently, app.R, test_app.R and SummarizedExperiment_App.R all host the same code, with different git histories as different people were working on different files.
